- 수정: 홈 시트를 비교 화면처럼 접히는 시트로, 칩은 선택된 것이 위에 오게 하고 겹침을 피하고, 버튼에 최소 너비를 준다.

- [x] 8-1. 홈 지도 (접히는 시트)
- [x] 8-2. 경로 칩 겹침
- [x] 8-3. "자세히" 버튼 너비
- 확인: 에뮬레이터를 360×640dp(`wm size 720x1280`, density 320)로 바꿔 확인한 뒤 원래대로 되돌림.
  - 8-1: 홈 아래 패널을 `BottomSheet`(끌기·손잡이 탭)로 바꿈. 펼쳤을 때 지도가 160dp 보다 좁아지면 사용자가 정하기 전까지 접힌 채로 보여 줌(접힘 = 손잡이 + 내 운전 성향 카드). 360×640dp 에서 접힌 채로 시작해 지도가 약 60dp 띠에서 약 280dp 로 넓어짐, 손잡이로 펼치면 갈 만한 곳 2곳이 보이고 누를 수 있음. 411×914dp 에서는 이전처럼 펼친 채로 시작하고, 손잡이 탭·끌기로 접고 펴짐(카드 위에서 끌어도 카드가 눌리지 않음). "이어서 볼까요?" 패널은 그대로 둠.
  - 8-2: 칩 겹침을 푸는 순수 함수 `spreadChips`(`src/map/chipAnchor.ts`, 단위 테스트 5개): 가로로 겹치는 칩을 세로로 쌓고, 보이는 범위 아래로 넘치면 위로 올림. 선택과 무관하게 위치가 정해져 다른 경로를 골라도 칩이 자리를 바꾸지 않고, 선택한 칩은 맨 위에 그림. 360×640dp 경로 비교에서 C·A·B 칩이 겹치지 않고 4dp 간격으로 쌓여 모두 읽힘.
  - 8-3: "자세히" 버튼을 글자 폭만큼(flexShrink 0), 안내 시작 버튼이 나머지 폭을 쓰게 바꿈. 360×640dp 에서 "자세히"가 한 줄이고 두 버튼 높이가 같음(56dp). 큰 글자에서 세로로 쌓이는 동작은 그대로.
